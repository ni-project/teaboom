## Getting Started

1] Установите зависимости:

```bash
npm install
# or
yarn install
```

2] Запустите development server:

```bash
npm run dev
# or
yarn dev
```

3] Откройте [http://localhost:3000](http://localhost:3000) если не открылось автоматически после запуска.

## Структура

```bash
/src
  /assets      | Иконки и изображения
  /page
    product.js | Скрипт для страницы "Продукт"
  /source      | Данные для страницы "Продукт"
  /styles      | Стили приложения 
  app.js       | Точка входа js
```
